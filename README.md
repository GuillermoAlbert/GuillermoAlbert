### 🇬🇧 About

Full Stack Developer at **CGI** (banking sector, France · Java / Angular). Before that, 2+ years at **Inetum** on platforms for **FranceAgriMer**, the French public agency that manages agricultural aid: a legacy JSF / Oracle application and a new Angular / Spring one taken to go-live.

Outside work, I run in production an **operations assistant built on LLM APIs** for a real SME (self-hosted RAG, human-in-the-loop) and an LLM-assisted invoice pipeline, on my own **homelab** (Proxmox, 9 LXC containers). I work with AI agents (Claude Code, MCP) from a spec I write myself; tests and review decide what ships.

I come from biology research: 3 publications, including AI-based detection of tagged animals in camera-trap images (_Ibis_, 2022).

### 🇪🇸 Sobre mí
